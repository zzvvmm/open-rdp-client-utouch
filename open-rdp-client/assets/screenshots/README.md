Native screenshots for Open RDP Client. The dashboard captures show the 0.3.0
development UI; session and settings references are retained from 0.2.0.

Captured from the native Qt/QML application using isolated
app data and the built-in interactive demo. The remote desktop shown is the
app's offline simulation. No saved user PCs or credentials are included.

- `01-saved-pcs-dark.png`: redesigned PC library in dark mode (390 × 844).
- `02-demo-session.png`: landscape demo session and pointer controls (1640 × 900).
- `03-session-shortcuts.png`: expanded session controls and shortcuts (1640 × 900).
- `04-settings.png`: update checks and preferences (900 × 1640).
- `05-saved-pcs-light.png`: redesigned PC library in light mode (390 × 844).

CI captures additional desktop and mobile sizes, grid/list layouts, and enlarged
text under `build/ui/`. Dashboard samples use fictional `.example.test`/`192.0.2.x`
addresses. Only the built-in demo connects; these images are not evidence of a
real Windows/xrdp server connection.
