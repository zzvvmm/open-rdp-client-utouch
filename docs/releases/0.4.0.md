# Open RDP Client v0.4.0

Open RDP Client now runs on Linux desktop as well as Ubuntu Touch. Both
frontends share the RDP engine and gain a redesigned PC library, temporary
Quick Connect, and clearer connection feedback.

## Linux desktop

- Add a Qt 6 desktop app with keyboard and mouse input, clipboard sync, audio,
  dynamic or fixed resolution, fullscreen, zoom, and optional touch controls.
- Provide separate **amd64 DEB packages for Ubuntu 24.04 and Debian 13**.
  Download the package for your distribution from this GitHub release.
- Add PCs, Accounts, and Settings navigation, responsive grid/list layouts,
  light/dark themes, reusable accounts, and certificate management.
- Reserve **Ctrl+Alt+Enter** for fullscreen and forward Escape to the remote
  session. Release held input when focus is lost or a dialog opens.
- Desktop upgrades use the releases link in Settings. Ubuntu Touch retains
  OpenStore updates, its package identity, and existing saved data. Desktop
  uses its own storage; profiles are not migrated automatically.

## PC library and daily workflows

- Browse All, Favorites, or Recent PCs; search names, addresses, and groups.
  Filter groups, sort by name/address/last connection, and remember grid/list
  and sort preferences. Recent records successful connections only.
- Create or assign groups in the PC editor, rename a group across its PCs, or
  remove a group while keeping its PCs in Saved PCs.
- Use **Quick Connect** for a temporary connection, choosing a saved account
  or entering credentials when prompted. Save the PC explicitly from the
  session when needed. Temporary PCs stay out of saved profiles, Recent, and
  thumbnail storage until saved; entering a password does not save an account.
- Organize PC settings into General, Display, and Devices. Use **Save** or
  **Save & Connect**, with validation and save errors kept in the editor.
- Refresh Ubuntu Touch with responsive PC cards, compact rows, library
  options, group management, and touch actions while retaining Lomiri controls
  and bottom navigation.

## Connection reliability

- Show connection stages, cancellation, persistent failure details, Retry,
  and Back to PCs. Retry resolves saved credentials again or prompts.
- Confirm before replacing an active session and ignore late events from
  cancelled or replaced connection attempts.
- Fix desktop thumbnail URLs and delivery of action errors to the UI. Keep
  credential and certificate prompts associated with the current connection.

## Compatibility and validation

- One window and one active session. Ubuntu Touch packages remain available
  for amd64 and arm64, targeting `ubuntu-touch-24.04-1.x`.
- Rust tests cover both platform feature selections; native Qt 5 and Qt 6
  tests cover library workflows, prompts, input release, and resolution modes.
  Package checks include Clickable review and installed DEB/demo startup on
  Ubuntu 24.04 and Debian 13. CI publishes the tested DEBs with checksums and
  their source commit.
- Native screenshots use isolated data and the offline demo. Offline checks
  do not establish Windows server interoperability. A native Qt 5 frontend
  also authenticated to local xrdp, received desktop frames, and completed
  portrait/landscape/keyboard-area dynamic resizes without reconnecting.
  Physical Ubuntu Touch
  hardware and real Windows server, clipboard, and audio interoperability
  have not been revalidated for this release.
- Cloud workspaces, gateways, simultaneous sessions, multiple monitors, and
  folder sharing remain outside this release.
