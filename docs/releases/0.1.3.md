# Open RDP Client v0.1.3

Released October 25, 2026 for Ubuntu Touch 24.04 on arm64 and amd64.

The on-screen keyboard now stays hidden until you request it, making remote
desktop navigation and shortcuts more predictable.

## Fixed

- Keep the on-screen keyboard closed when a session starts and while using
  pointer controls or shortcuts after dismissing it.
- Hide the keyboard when leaving a session or backgrounding the app. Returning
  to the app does not reopen it automatically.
- Keep hardware keyboard typing and shortcuts working while the on-screen
  keyboard is hidden.
- Make both session keyboard buttons toggle the on-screen keyboard without
  hiding the extra key bar.

## Store listing

- Added five native screenshots showing the saved PCs dashboard in dark and
  light themes, demo session controls, shortcuts, and preferences.
- Added source code and issue-tracker links to the OpenStore listing.

## Validation

- 17 Rust tests and 20 QML checks passed, including keyboard dismissal and focus
  restoration coverage.
- Both architecture packages passed package review.
- Both public OpenStore downloads matched the local release SHA-512 checksums.
- GitHub CI passed for release commit
  [`e63d064`](https://github.com/zzvvmm/open-rdp-client-utouch/commit/e63d06497038aa19d3da90f3d49f87f0f83a4219).

The package ID remains `rdp-client-ut.zzvvmm`, preserving compatibility with
existing installations and saved app data.
