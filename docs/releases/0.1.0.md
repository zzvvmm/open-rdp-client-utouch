# Open RDP Client v0.1.0

Originally published October 24, 2026 for Ubuntu Touch 24.04 on arm64 and amd64.
This initial version was named **Windows App RDP**; it was renamed Open RDP
Client in v0.1.1.

## Initial release

- Native QtQuick/Lomiri interface backed by the Rust IronRDP engine.
- Saved PCs dashboard with search, favorites, groups, session preview
  thumbnails, and an interactive offline Windows 11 demo.
- RDP connections with NLA/CredSSP authentication and certificate inspection
  using Trust-On-First-Use fingerprint verification.
- Virtual trackpad and direct-touch input modes, right-click gestures, and
  desktop zoom controls.
- Extended keyboard bar with sticky modifiers, navigation keys, function keys,
  and common Windows shortcuts.
- Dynamic remote display resizing, bidirectional text clipboard sync, and
  remote audio playback.
- Reusable user accounts with encrypted local password storage.
- Dark and light appearance settings and configurable trackpad speed.
