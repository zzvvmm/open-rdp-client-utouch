# Open RDP Client v0.2.1

This release improves PC address entry, connection reliability, and touch
session behavior.

## Fixed

- Preserve hostnames, IPv6 addresses, and custom ports when saving or editing
  PCs. Disable keyboard rewriting in the address field and commit pending input
  before saving, avoiding changed or truncated addresses.
- Resolve names separately from connection attempts and try IPv4/IPv6 routes
  without letting a stalled address block a working route. Kerberos UDP
  authentication can use LAN/VPN routes and IPv6 domain controllers; replies
  are bounded and accepted only from the selected domain controller.
- Report DNS, TCP, and handshake failures separately with troubleshooting
  hints, bound stalled connection stages, and cancel pending connections when
  leaving the session. A connection troubleshooting guide is included.
- Restore negotiated bulk decompression after desktop reactivation so screen
  updates remain readable after a server resize.
- Ignore unknown Fast-Path update codes without discarding later updates in the
  same packet, avoiding session termination on unsupported server updates.
- Handle xrdp's six-byte Server Deactivate All message by following the normal
  display reactivation path instead of failing to decode a Share Control
  header.

## Improved

- Use Direct Touch by default for new PCs while preserving saved Trackpad
  preferences.
- Keep the virtual key bar visible above the software keyboard in portrait and
  landscape, and release held pointer buttons when the session view changes
  size.
- Keep the authenticated session during rotation, wait for display-control
  capabilities before requesting remote resize, and fit the existing desktop
  locally when remote resizing is unsupported. Fixed-resolution profiles keep
  their selected size, and resize requests preserve display scale.

## Validation and limitations

- 37 Rust tests and 65 QML checks pass. Resize tests exercise protocol
  encoding with simulated channel setup and capabilities; QML layout tests use
  a canvas stub.
- Both amd64 and arm64 packages build and pass Clickable review.
- A native offline demo stayed connected through portrait, landscape, reduced
  keyboard space, and a return to portrait.
- Physical-device testing with a real RDP server verified session continuity
  through rotation, software-keyboard and key-bar behavior, and VPN/domain
  authentication.
