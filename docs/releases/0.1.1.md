# Open RDP Client v0.1.1

Originally published October 24, 2026 for Ubuntu Touch 24.04 on arm64 and amd64.

## Changed

- Renamed the app from Windows App RDP to **Open RDP Client**.
- Updated the launcher name, window title, app header, About screen,
  documentation, and translation metadata to use the new name.
- Improved the header layout on small screens so long titles are elided
  instead of overlapping the action buttons.
- Allowed the About title to wrap on narrow displays.
- Added desktop-file identification for the app window and stripped release
  binaries and unused linked code.

The package ID remains `rdp-client-ut.zzvvmm`, preserving compatibility with
existing installations and saved app data.
