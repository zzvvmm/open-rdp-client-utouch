# Open RDP Client v0.2.0

Released October 26, 2026 for Ubuntu Touch 24.04 on arm64 and amd64.

This release adds automatic and manual update checks with changelogs and a
choice of when to install an update.

## Added

- **Settings → Updates** with an **Automatically check for updates** option,
  enabled by default. Automatic checks run at most once a day when the app is
  opened or resumed.
- A manual **Check for updates** action that works even when automatic checks
  are disabled and can show a previously skipped version.
- An update popup with the compatible release's changelog and three actions:
  **Update Now**, **Update Later**, and **Skip This Version**.
- Persistent update preferences and skipped versions across app restarts.
- Checking, up-to-date, unavailable, and connection-error feedback in Settings.

**Update Now** opens the app's OpenStore page to download and install the
update. **Update Later** dismisses the popup until the next due automatic check.
**Skip This Version** suppresses automatic prompts for that version while
allowing a newer version to be offered.

Update checks select stable releases matching the device's architecture and
installed framework. Prompts wait until the app is active and outside the
remote session view. Failed automatic checks stay quiet, and existing settings
are preserved when loading preferences saved by earlier versions.

## Development workflow

- Added the development and release guide, reusable release skill, and
  historical release notes.
- Added helpers for consistent application version bumps and verification of
  both public OpenStore downloads against local packages.

## Validation

- 20 Rust tests and 47 QML checks cover settings migration and persistence,
  device compatibility, skip/manual-check behavior, timeouts, error handling,
  and portrait/landscape popup layouts.
- Desktop integration checks exercised the live OpenStore HTTPS API, popup
  wiring, and preference persistence after restarting the app.
- UI validation used native desktop rendering and the offline demo; this
  release does not change the RDP protocol implementation.
