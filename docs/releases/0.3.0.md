# Open RDP Client v0.3.0

This release adds privacy-conscious error reporting and improves Dynamic (Fit)
session rendering and connection defaults.

## Added

- Add **Report Errors** in Settings, enabled by default and remembered across
  restarts. Turning it off immediately stops new reports. Only sanitized error
  categories, safe source locations, and app/platform metadata are sent; raw
  messages, connection details, credentials, account data, clipboard contents,
  screenshots, and local paths are excluded. See
  [Error reporting](../ERROR_REPORTING.md) for details.

## Improved

- Put **Device Native** and **Direct Touch** first and select them for new PCs.
  Migrate older global defaults once while preserving other preferences and
  existing saved-PC resolution and input choices.

## Fixed

- Fix blank or corrupted Dynamic (Fit) desktops after connection or rotation.
  Wait for desktop pixels before the initial resize, preserve RemoteFX codec,
  compression, and fragmented-update state, and replay traffic interleaved with
  display reactivation.
- Disable outer RDP bulk compression to avoid resize corruption with the current
  engine and xrdp; RemoteFX graphics compression remains enabled.
- Clear resized framebuffers using the previous row stride.

## Validation and limitations

- 52 Rust tests and 68 QML checks pass; both amd64 and arm64 packages pass
  Clickable review.
- A local xrdp/Xorg session rendered correctly through initial Dynamic (Fit),
  landscape, and portrait resizes; the resulting terminal image was inspected
  for coherent pixels.
- A physical Ubuntu Touch device installed and launched the updated app. The
  one-time default migration was verified and the saved-PC file remained
  unchanged. The previously affected remote host still needs a device retest.
- Error-reporting delivery and opt-out behavior were verified through the
  application's native initialization paths. Native signal crashes and
  minidumps are not captured.
