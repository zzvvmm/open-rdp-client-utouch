# Open RDP Client v0.1.2

Originally published October 25, 2026 for Ubuntu Touch 24.04 on arm64 and amd64.

This release improves remote desktop input on touchscreens and with hardware
keyboards and mice.

## Added

- Dedicated **Left**, **Right**, and **Double** click buttons.
- **Drag** lock for moving windows or selecting text across several swipes.
- **Precise** mode for positioning the pointer over small targets.
- Hardware keyboard shortcut handling and Linux-friendly shortcuts, including
  `Ctrl+Alt+T`, `Alt+F2`, `Alt+F4`, `Ctrl+Alt+D`, and terminal copy/paste chords.
- QML interaction regression tests, run by the amd64 CI build.

## Improved

- Trackpad tapping, double-tapping, long-press dragging, two-finger
  right-clicking, and scrolling.
- Direct-touch dragging and long-press right-click behavior; touches in the
  black border around the desktop are ignored.
- Release of held mouse buttons when gestures are cancelled, input modes
  change, or the session is left.
- Physical mouse buttons, dragging, wheel input, and balanced keyboard
  navigation press/release events.
- Pointer-following pan when zoomed in trackpad mode.
- Session controls and the shortcuts drawer on landscape displays.

Shortcut behavior depends on the remote desktop's configured key bindings.
